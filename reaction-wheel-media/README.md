# Reaction Wheel Portfolio Media

This folder contains the strongest final photos and the recorded demo, renamed for direct use in the portfolio repo.

## Recommended page use

1. `reaction-wheel-hero.jpg`
   - Main / hero image.
   - Fully assembled system at a clean three-quarter angle.

2. `reaction-wheel-wireless-control-demo.mp4`
   - Primary demo video.
   - Shows the physical platform responding to wireless closed-loop commands with the live target/angle plot visible.

3. `reaction-wheel-exposed-wheel.jpg`
   - Best mechanism overview.
   - Top-down view with the guard removed, showing the weighted reaction wheel and surrounding electronics.

4. `reaction-wheel-electronics-overhead.jpg`
   - Electronics / controls detail.
   - Good for a section discussing the Arduino Nano, power conversion, motor drive, and sensor wiring.

5. `reaction-wheel-motor-bluetooth-detail.jpg`
   - Motor / wireless integration detail.
   - Shows the drive assembly and BlueSMiRF area clearly.

6. `reaction-wheel-power-layout.jpg`
   - Underside power layout.
   - Useful for discussing battery placement and the effort to keep mass closer to the rotation axis.

7. `reaction-wheel-bearing-base.jpg`
   - Base / bearing architecture.
   - Clean detail of the central shaft, bearing support, and fixed base.

## Suggested order on the page

Hero photo → short project overview → demo video → performance/results → exposed-wheel photo → electronics/motor details → bearing/power-layout details.
